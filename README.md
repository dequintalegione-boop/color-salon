Сайт салона Color. Запуск: открыть index.html в браузере (сервер не нужен).
Фото: положить в assets/ (work1.jpg … work6.jpg) или указать имена в таблице.
Таблица: table/color-salon-table.xlsx -> загрузить в Google Таблицы, открыть доступ по ссылке (читатель),
вставить ID таблицы в index.html в строку SHEET_ID. Подробности — на вкладке «Инструкция».
